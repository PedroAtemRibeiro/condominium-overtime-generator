# Automacao de Mapas de Horas 
## Funcionalidades

- Leitura automática de cadastros em PDF
- Identificação de funcionários e cargos
- Classificação automática de escalas
- Geração de mapas de horas em PDF
- Inclusão automática de feriados do mês
- Geração em lote para múltiplos condomínios
- Executável para usuários finais
